# GameZone 🎮

A responsive, interactive mini-game and learning playground with four experiences:

- 🍝 **Cooking Challenge** — tick off ingredients and switch between 2 or 4 servings.
- 🌌 **Space Explorer** — explore the stages in the life of a Sun-like star.
- ⚽ **Offside Challenge** — move a receiver on the pitch and learn the offside-position rule.
- 📚 **Library Explorer** — browse six famous libraries and read quick facts.

## Run locally

No build tools, API keys, or external JavaScript dependencies are required.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.

The original hosted version remains available at https://gamezone-play.higgsfield.app.

## Tech

HTML, CSS, and vanilla JavaScript. Responsive layout, accessible controls, and inline SVG illustrations.
